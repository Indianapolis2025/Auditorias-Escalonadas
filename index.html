Dashboard

Acompanhe os principais resultados do sistema em uma única tela.

Para que serve?

O Dashboard apresenta a quantidade de auditorias, respostas, percentuais de Conforme, Parcial e Não conforme, pendências e os gráficos de acompanhamento.

Filtros

Use os filtros de período, local, setor e auditor. Também é possível selecionar a planta Fundição ou Usinagem para analisar somente aquela operação.

Nota da auditoria

A nota considera A = 100%, P = 50% e N = 0%. Os itens marcados como N.A. não entram no cálculo da média.

PDF do Dashboard

Aplique os filtros desejados e clique em Exportar Dashboard em PDF. Para impressão, utilize A4, preferencialmente Paisagem, e habilite os gráficos/imagens de plano de fundo.

Nova Auditoria

Como lançar uma auditoria corretamente, do início ao salvamento.

1. Selecione a planta

Escolha FUNDIÇÃO ou USINAGEM. O sistema carregará automaticamente o questionário correspondente.

2. Preencha os dados

Informe local, setor, colaborador, auditor e data. O auditor disponível é filtrado conforme a planta.

3. Responda cada pergunta

A = Conforme; P = Parcial; N = Não conforme; N.A. = Não aplicável.

4. Justificativas

Ao marcar P ou N, a justificativa é obrigatória. O item será levado para Pendências. Para N.A., a justificativa não é obrigatória e o item não gera pendência.

5. Finalize

Confira as respostas antes de salvar. A nota percentual será calculada automaticamente desconsiderando os itens N.A.

⚠

Pendências

Área para tratar respostas Parciais e Não conformes.

Quando aparece?

Uma pergunta entra em Pendências quando recebe P ou N. O sistema exige a justificativa no lançamento.

Justificativa

A justificativa pode ser revisada/atualizada conforme o tratamento da ocorrência.

Ação tomada

O responsável pelo setor pode registrar a Ação Tomada para informar o que foi feito para tratar a pendência.

N.A.

Itens marcados como N.A. — Não aplicável não entram em Pendências.

📅

Programação

Organize as auditorias do mês por planta, colaborador e auditor.

1. Escolha o mês

Selecione o mês da programação e a planta. A programação é organizada separadamente para Fundição e Usinagem.

2. Distribuição

O sistema distribui os colaboradores e associa somente auditores autorizados para a planta selecionada.

3. Auditores por planta

Fundição: Ryan A, Tiago B, Gabriel A, Antônio D e Jambres.
Usinagem: Ryan A, Tiago B, Johnny, Josemario e Jose Raimundo.

4. Auditoria atrasada

Se uma auditoria não for realizada até a data limite, ela passa a ser identificada como atrasada. Ao iniciar a auditoria pela programação, a data limite é preservada para o cálculo correto.

5. Nova programação

Ao gerar/atualizar a programação, confira planta, colaborador, auditor e período antes de iniciar os lançamentos.

☁ Configurar banco online

Depois de publicar este HTML em um endereço HTTPS, estes dados conectam todos os computadores e iPhones ao mesmo banco. O sistema usa Firebase Authentication anônima e Cloud Firestore.

Como obter estes dados: no Firebase Console, crie um projeto, adicione um app Web e copie o objeto firebaseConfig. Ative Authentication → Anonymous e crie o Cloud Firestore. O botão abaixo salva apenas a configuração neste dispositivo.

Importante: a configuração do Firebase não é uma senha. Não coloque neste HTML nenhuma chave privada ou service account.
